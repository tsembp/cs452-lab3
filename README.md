# CS452 Lab 03: Go

A small Go application that demonstrates modules, packages, error handling, unit tests, random greetings, and greetings for multiple people.

## Run

```bash
go run .
```

## Test

```bash
go test ./...
```

## Features

- Returns a random greeting for a name.
- Returns an error when the name is empty.
- Generates greetings for multiple names using a map.
